`--> ["what this is"]`

Kite is a reactive UI package for Roblox, created by Makel, or also known
under the alias: Savi.

Three shapes, one rule:

```text
source   a value that changes
derive   a value that is computed
effect   work that happens
```

A derive and an effect remember what they read while they run. When one of
those things changes, they run again. Nothing else.

Every instance under this repository has its own README. Please view those.

`--> ["paradigm"]`

This is the first version of it. A reactive UI package.

It should not just be a tool. It should literally help you in every way:

- it reads your tree before you run it and answers like a person
- it shows you what every function does when you hover it
- it answers in the console when you ask `kite.help("spring")`
- it counts itself, so you can argue with numbers
- it never makes you write a dependency array

It is not a framework. It is not a standard library.
